# Асық ату

«Асық ату» — небольшая браузерная игра на меткость по мотивам традиционной казахской игры с асыками. Она подойдёт тем, кто хочет познакомиться с игрой, сыграть короткий раунд на телефоне или посоревноваться вдвоём на одном устройстве. Интерфейс доступен на русском и казахском языках.

## Правила

Асыки размещены внутри круга, игрок стоит за линией броска. Чтобы бросить сақа, зажмите её, потяните назад и отпустите. Направление жеста задаёт направление броска, длина жеста — его силу. За каждый асык, полностью вышедший за границу круга, начисляется одно очко. Один асык может принести очко только один раз. В раунде пять бросков; в игре вдвоём игроки бросают по очереди.

Звания по результату: 1–2 очка — «Новичок», 3–4 — «Мергенді», все асыки на уровне — «Шебер». Наберите не менее трёх очков, чтобы открыть следующий уровень.

## Как правила работают в браузере

Игра показывает поле сверху и принимает жесты мыши или касания через Pointer Events. Физика круговых тел рассчитывается самостоятельно с фиксированным шагом: учитываются импульсы, столкновения и трение. Canvas 2D масштабируется под экран, а `touch-action: none` не даёт браузеру перехватить игровой жест.

Браузерная версия сохраняет короткий раунд и понятное управление: асыки не подбирают вручную, а покинувшие круг мишени засчитываются автоматически. Игра включает пять расстановок возрастающей сложности, тренировку, игру вдвоём и ежедневную расстановку, одинаковую для календарной даты. Ежедневный результат можно скопировать и отправить.

## Добавлено от себя

- Первичное обучение из трёх шагов и отдельный экран правил.
- Тренировка и локальная игра вдвоём на одном устройстве.
- Пять уровней, открытие следующего уровня за результат от трёх очков и сохранение прогресса.
- Ежедневное испытание с расстановкой, детерминированной датой, сохранением результата и его копированием.
- Подсказки о направлении и силе броска, личный рекорд, WebAudio-эффекты, частицы, анимация столкновений и переключатель звука.
- Русский и қазақша интерфейс, тёплое оформление с кодовым орнаментом қошқар мүйіз.

## Запуск

Требуется установленный Node.js и npm.

```sh
npm install
npm run dev
```

Vite напечатает локальный адрес для браузера. Production-сборка создаётся командой `npm run build`, локально её можно открыть командой `npm run preview`.

## Деплой на GitHub Pages

Workflow в `.github/workflows/deploy.yml` собирает проект при push в ветку `main` и публикует `dist` через GitHub Pages. В настройках репозитория выберите **Settings → Pages → Source: GitHub Actions**. После успешного workflow страница будет доступна по адресу GitHub Pages этого репозитория.

## Технологии

- Vite и JavaScript ES-модули.
- Canvas 2D для поля и анимации.
- Собственная физика круговых тел с фиксированным шагом.
- WebAudio API для звуков без аудиофайлов.
- CSS и кодовый SVG для оформления и орнамента.
- `localStorage` для рекорда, настроек, ежедневного результата и прогресса.
- GitHub Actions для сборки и публикации на GitHub Pages.

## Инструменты и заимствования

- AI-инструмент разработки: GitHub Copilot.
- Заимствованные компоненты и игровые библиотеки: нет.
- Внешние изображения и звуковые файлы: нет.

## Известные ограничения

- Физика — игровая аппроксимация, а не полная реконструкция всех региональных вариантов традиционных правил.
- Прогресс и рекорд хранятся только в `localStorage` текущего браузера; аккаунтов и синхронизации между устройствами нет.
- Ежедневный результат хранится локально и не отправляется на сервер. Расстановка определяется календарной датой UTC.
- Звуки синтезируются WebAudio; браузер включает звук только после пользовательского взаимодействия, а некоторые режимы приватности могут отключать аудио или локальное хранилище.
- В двухпользовательском режиме игроки делят один экран и по очереди используют одно устройство.
